## About Me

I'm a **Cloud Security Engineer and Cybersecurity Researcher** with dual academic qualifications in **Cybersecurity Engineering and Architecture**, complemented by postgraduate education, software engineering expertise, and professional certifications in cloud computing, artificial intelligence, and data science.

My interdisciplinary background combines **security engineering, systems thinking, and architectural design principles**, allowing me to approach complex technological challenges from both technical and strategic perspectives.

I specialize in securing enterprise cloud environments, implementing Zero Trust architectures, automating security controls, and assessing application security.

My research interests lie at the intersection of **artificial intelligence, cybersecurity, and emerging threat landscapes**, with a particular focus on generative AI and its implications for offensive and defensive security.

- 🔐 **Cloud Security:** Microsoft Entra ID, Microsoft Intune, AWS, IAM, Conditional Access, Zero Trust.
- 🛡️ **Security Engineering:** Endpoint hardening, EDR, vulnerability management, SAST/DAST, API security.
- ⚙️ **Security Automation:** Microsoft Graph API, PowerShell, Python, REST APIs.
- 🤖 **AI Security & Research:** Generative AI threats, machine learning, cybersecurity research.
- 💻 **Software Engineering:** JavaScript, TypeScript, Python, React, Node.js, MongoDB.
- 🎓 **Professional Development:** Advanced cybersecurity, cloud architecture, security governance, and applied AI.
